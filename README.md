# Eyes to Earth — ICYMI

Estrutura inicial de um website estático para apresentar o projecto Eyes to Earth.

## Estrutura

```text
eyes-to-earth-icymi/
├── index.html
├── style.css
├── README.md
└── images/
    ├── hero-incomati.jpg

    ├── students-working.jpg

    ├── certificates-group.jpg
    └── galeria/
```

## Como usar

1. Extraia o ficheiro ZIP.
2. Substitua os nomes de exemplo pelas fotografias reais, mantendo os nomes indicados na pasta `images/` (ou actualize os caminhos no `index.html` e no `style.css`).
3. Abra `index.html` no navegador para pré-visualizar.
4. Para publicar no GitHub, crie um repositório e carregue os ficheiros e pastas.
5. Para publicar como site, active **Settings → Pages** no repositório e escolha a branch e a pasta raiz (`/root`).

## Imagens

As imagens não estão incluídas. Coloque os ficheiros de fotografia correspondentes na pasta `images/`. A pasta `images/galeria/` está preparada para fotografias adicionais.
